プライバシーポリシー

最終更新: 2026-10-19

対象

このポリシーは OAuth クライアント「Personal Drive Sync」に適用されます。利用者は開発者本人のみです。

アクセスする情報

  • Google Drive のファイルとフォルダ(Google Drive API のスコープ経由)。用途は開発者自身の Google Drive へのファイルのアップロードと、アップロード済みファイルの照合だけです。
  • Google アカウントのその他の情報(連絡先・メール・カレンダーなど)にはアクセスしません。

保存と共有

  • 認可トークンは開発者のパソコン内の rclone 設定ファイルにのみ保存されます。
  • 取得した情報を第三者に提供・販売することはありません。外部サーバーへ送信することもありません。
  • 認可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

Google API サービスのユーザーデータに関するポリシー

本クライアントは、Google API から取得した情報の利用について、Google API Services User Data Policy(限定的な使用の要件を含む)を遵守します。

連絡先

GitHub: fukuda-sho

English summary

Personal Drive Sync is a personal OAuth client for the open-source tool rclone. It accesses Google Drive files only to upload files from the developer's own computer to the developer's own Google Drive. Tokens are stored only on the developer's computer. No data is shared with or sold to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google account's third-party access settings.
